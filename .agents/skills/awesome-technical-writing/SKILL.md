# Awesome Technical Writing Guide

Use this skill when drafting or reviewing technical documentation, security guides, API specifications, and release notes:

1. **Clarity & Brevity**: Prefer active voice, simple sentence structures, and precise terminology.
2. **Audience-First**: Identify the target reader (developer, end user, or security auditor) and match technical depth.
3. **Reproducibility**: Provide exact commands, realistic examples, and step-by-step verification procedures.
4. **Consistency**: Use unified naming conventions, typography, and token definitions.
